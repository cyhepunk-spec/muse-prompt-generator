# Muse 提示词生成器

输入一个主题或赛道，生成一条可以直接粘贴到 Muse 里建 Space 的完整提示词。

- 24 小时监控、每小时更新、到期提醒
- 5–6 个分类、7 项指标打分（满分 10 分）
- 关键词搜索与智能问答
- 热门情报 / 核心推荐 / 分类情报三段式
- 每条情报 9 个字段

内置 10 个赛道：AI 产业、黑客与网络安全、贵州独山县、海南儋州市、海南省农业、贵州省农业、爵士乐吉他学习课程、数码产品折扣、全球数字生活优惠、农业科技资料；其他赛道按通用骨架拆 6 类。

输出框可编辑、一键复制、可下载 .txt；历史存在浏览器本地；本周榜只按本机近 7 天真实生成次数排。

## 使用

直接打开 `index.html`，或访问部署地址（Cloudflare Pages，绑定域名 catji.de5.net）。

纯前端单文件，无需后端、无需密钥。
